自渡台隐私政策

更新日期：2026年11月11日 · 生效日期：2026年11月11日

适用版本：自渡台鸿蒙应用 1.0.0（包名：com.zidutai.study）

本政策由自渡台开发者（以下简称“我们”，联系方式见第九节）提供，说明您使用自渡台时，应用如何处理您主动输入或导入的信息。自渡台是用于音乐考研学习计划、科目进度、复盘及个人生活记录管理的工具。

核心说明：当前版本无需注册或登录，核心功能离线运行。您在应用中填写的学习、状态和收支记录保存在设备本机，不会通过本应用上传到我们的服务器。我们没有用于接收这些记录的开发者服务器，也不提供账号同步、广告投放或行为统计功能。

一、处理哪些信息及用途

应用仅根据您的操作在本机保存和使用以下内容，您可以不使用其中某项功能：

  • 目标与学习记录：考试目标日期、科目和学习单元名称、掌握程度、复习日期、笔记、计划内容及完成状态、学习时长和复盘文字，用于展示倒计时、安排学习及记录进度。
  • 个人状态：您主动填写的心情、睡眠时长、运动时长、日记和休息安排，用于个人状态记录。应用不会从传感器或健康服务自动读取这些信息。
  • 收支记录：您主动填写的收入或支出金额、日期、分类及备注，用于本机记账和汇总。应用不连接银行或支付账户，不读取账户密码或支付记录。
  • 备份内容：您主动选择导入的自渡台 JSON 文件中的应用记录和设置，用于恢复数据；兼容的旧版历史记录也可能保留在本机并随备份导出。
  • 运行所需的本机信息：应用使用设备当前日期时间显示日历和安排记录，并生成仅用于区分本机记录的标识。这些记录标识不是设备唯一标识，不上传给我们。

个人状态、日记和收支内容可能涉及健康、财务或其他敏感事项。请只输入实现您个人记录目的所需的内容，避免填写身份证件号码、银行账户、密码或无关第三方的个人信息。您不填写状态或记账内容，不影响使用学习计划等其他功能。

本版本不要求提供手机号、邮箱、真实姓名或身份信息，不读取通讯录、定位、相机、麦克风或相册，也不主动获取设备广告标识。

二、设备权限与文件选择

当前应用未声明互联网、通讯录、定位、相机、麦克风等权限。只有您主动点击导入或导出备份时，才调用系统文件选择器：

  • 导出时，您决定保存位置，应用将当前记录写入您选定的 JSON 文件。
  • 导入时，应用只读取您选定的文件，校验备份格式，并在您确认后替换当前记录；不会扫描其他文件。
  • 您可以取消文件选择，取消不影响已有记录和其他功能。

三、信息保存地点与期限

应用记录保存在您当前设备的应用本地存储中，不传输或保存至开发者服务器，因此本版本不存在由我们安排的服务器存储国家或地区。我们不对这些本机记录进行跨境传输。

记录会持续保留，直至您删除相应内容、清除应用数据，或设备系统执行相应数据清理。卸载应用也可能导致本机记录丢失，请在操作前导出需要保留的备份。

已导出的备份是独立文件，不会因为删除应用内记录而自动删除。其保存期限由您决定；如果您选择云盘等保存位置、启用设备系统备份，相关存储与传输由您选择的服务及其政策管理，不属于本应用提供的同步服务。

四、共享、转让、第三方服务与公开披露

本版本没有广告、第三方登录、开发者行为统计或云同步 SDK。应用基于鸿蒙系统组件运行，使用 ArkWeb 显示随包提供的离线界面，使用系统文件选择器处理您主动发起的备份操作。

我们不会通过本应用将您的本机记录出售、共享、转让给第三方或公开披露。您自行发送备份或将其存入第三方服务时，接收方可能读取文件内容，请自行确认接收对象和保存位置。

您下载、更新或参与 AppTest 测试时，华为平台可能依据其自身政策处理账号、安装或测试相关信息。此类平台处理独立于本应用的离线记录功能。

五、安全保护与备份提醒

应用使用系统提供的应用存储环境保存记录，不提供对外读取接口，并对导入的备份进行格式和大小校验。这些措施无法消除设备丢失、系统故障或误操作等所有风险。

当前版本没有额外的应用密码锁，导出的 JSON 备份也没有额外加密。能够访问备份的人可能读取其中的记录。请设置设备锁屏、妥善保管设备和文件，勿将包含私人日记、状态或收支信息的备份上传到公开仓库或公开链接。

六、您如何查看、更正、删除和导出信息

  • 查看与更正：在相应功能页面查看记录；对提供编辑入口的记录可直接修改并保存。
  • 删除：对提供删除入口的记录，可在应用内删除。需要移除全部本机应用数据时，可在系统允许的情况下使用应用数据清理功能；请先备份需要保留的内容。
  • 导出与恢复：在应用设置中主动导出 JSON 备份，或选择有效备份并确认导入。导入会替换当前记录，建议先导出当前数据。
  • 停止某项处理：停止填写相应功能，并删除已保存的相关内容；导出的文件需要在文件管理器或相应存储服务中另行删除。
  • 账号注销：本版本没有注册账号，无需办理账号注销。

我们无法远程查看、恢复或替您删除设备内的记录。您可以通过第九节的邮箱咨询操作方法。联系时请勿发送密码、验证码或整份私人备份；如需提供截图，请先遮挡无关个人信息。

七、未成年人保护

本应用面向音乐考研备考场景，不专门面向不满十四周岁的儿童。未成年人使用时，请由监护人指导，避免填写不必要的敏感内容。如监护人对记录处理有疑问，可以联系我们了解本机删除和导出方法。

八、政策更新及适用范围

本政策描述当前鸿蒙应用的实际功能。若以后增加联网、账号、统计或其他处理方式，我们会更新政策，并在适用时通过应用更新等方式告知、提供必要选择。本次不会因更新本政策网页而自动增加上述应用功能。

本政策网页本身用于公开查阅。打开该网页时，浏览器和网页托管服务可能按各自政策处理提供网页所需的访问数据；这与应用向开发者上传学习或生活记录不同。本网页未添加表单、追踪脚本或分析工具，也不加载外部字体或图片。
